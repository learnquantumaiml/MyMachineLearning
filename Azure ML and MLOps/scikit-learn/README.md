## Daily Scikit-learn Practice

Daily practice as part of my Azure MLOps and AI-300 preparation. Each day contains a standalone Python script, with no dependencies between exercises.

 - Scikit-learn is used to practise data preprocessing, model training, evaluation, and prediction. 
 - These exercises build the foundation for developing reproducible machine learning workflows and deploying models with Azure Machine Learning.

 When you need to use it?
 
 - Scikit-learn is particularly effective for structured or tabular data, such as customer records, transaction data, sensor measurements, and business metrics.
 - For deep learning involving images, audio, or large language models, frameworks such as PyTorch or TensorFlow are usually more appropriate.
 - In an MLOps workflow, scikit-learn is often used to create the baseline model, build preprocessing pipelines, compare algorithms, and then register or deploy the selected model through platforms such as Azure Machine Learning.
