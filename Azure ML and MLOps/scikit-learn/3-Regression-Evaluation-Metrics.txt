## Regression + Evaluation Metrics (MAE, RMSE, R²) + a peek at Regularization.

- I have tried to use this script to creates a fake apartment-rental dataset, trains two simple models (plain Linear Regression and Ridge Regression) to 
  predict monthly rent from features like size, bedrooms, distance, and age, then compares their accuracy and shows what each model “learned.”

What we can achieve from this?
- Understand basic regression workflows: Data creation → train/test split → model training → evaluation.
- Compare models: To see how adding regularization (Ridge) changes performance metrics (MAE, RMSE, R²) and shrinks coefficients to reduce overfitting.
- Interpret model weights: To inspect how much each feature (e.g., size_sqm, distance_km) influences rent in each model.
- Make predictions: To plug in a new apartment’s features and get a predicted rent.

To conclude, it’s a minimal, self-contained example of training, evaluating, and interpreting regression models in scikit-learn,
ideal for learning MLOps basics training purpose and if you want to experimenting with how data patterns affect model behavior.
