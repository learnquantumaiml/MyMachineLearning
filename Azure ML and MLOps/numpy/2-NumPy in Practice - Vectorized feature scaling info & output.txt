## NumPy in Practice — Vectorized feature scaling (standardization/normalization)

Key points to note:

-Machine learning models like linear regression, KNN, and neural networks are sensitive to the scale of numbers. 
-If "income" ranges in the tens of thousands and "score" ranges 0–1, the model can wrongly treat income as more important just because its numbers are bigger.
-Z-score standardization reshapes each column so it has mean 0 and standard deviation 1 — useful when your data roughly follows a bell curve.
-Min-Max normalization squeezes values into a 0–1 range — useful when you want a fixed bounded range (e.g., for neural network inputs).
-axis=0 means "operate down each column," and NumPy's broadcasting automatically applies the column stats to every row without a loop.

I demonstrated how to preprocess numerical data by applying feature scaling techniques such as z-score standardization and min-max normalization. 
This is an important step in preparing data for machine learning models in Azure AI workflows.
